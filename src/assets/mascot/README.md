# Mascote do ChefCalc

O app usa um mascote vetorial provisório (desenhado em `src/components/ui/Mascot.tsx`).

Para usar a versão personalizada (inspirada na sua foto):

1. Gere a ilustração do mascote (estilo vetorial, avental azul, chapéu de chef, fundo transparente).
2. Salve aqui com o nome **`chef-custom.svg`** (preferido) ou `chef-custom.png` / `chef-custom.webp`
   — quadrado, mínimo 512×512 px.
3. Faça commit e o deploy. O componente `Mascot` detecta o arquivo automaticamente
   e passa a usá-lo no painel de boas-vindas e nos estados vazios.

Não coloque a foto original aqui: use apenas a ilustração final do mascote.
