# Mascotes do ChefCalc

Cada página usa uma variante. Se uma variante faltar, o app usa `chef-custom` e, por último, o mascote vetorial provisório.

| Arquivo | Onde aparece |
|---|---|
| `chef-custom.webp` | Login, "Meus restaurantes", visão geral, carregamento (logo do avental em azul-claro) |
| `chef-hero.webp` | Primeira dobra da página inicial (versão maior do mesmo mascote) |
| `chef-sheets.webp` | Fichas técnicas, editor de ficha, impressão |
| `chef-ingredients.webp` | Insumos |
| `chef-shopping.webp` | Compras |
| `chef-finance.webp` | Financeiro, Simulador |
| `chef-converter.webp` | Conversão |

Para trocar: salve com o mesmo nome (svg, png ou webp; quadrado, fundo transparente, mín. 512 px).
